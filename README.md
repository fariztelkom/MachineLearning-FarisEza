Repositori ini berisi rangkuman per bab dari buku **Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (2nd Edition)** karya Aurélien Géron.
Rangkuman disusun per folder agar mudah dipelajari ulang dan dicari berdasarkan urutan bab.

## Struktur Folder
Folder bab menggunakan format dua digit: `01`, `02`, `03`, dan seterusnya.
Gunakan format ini agar urutan selalu benar di file explorer maupun GitHub.
